# Launcher icon

`mipmap-*/ic_launcher.png` is the Breeze `chronometer` glyph (white) on a rounded square in the app's
blue (`#3CA1DD`), rendered from `/usr/share/icons/breeze/actions/24/chronometer.svg`.

The glyph is from the KDE Breeze icon theme, **LGPL-3.0-or-later**, so the PNGs are under that licence
and not under the MIT licence of the rest of the repository.

Sizes: mdpi 48, hdpi 72, xhdpi 96, xxhdpi 144, xxxhdpi 192 px.
